# 商品品类映射（category-mapper）

## 何时使用

✅ **应该使用**:
- 新数据进来后，给新商品打统一品类（**增量**：已存在 ID 不动，新 ID 自动补标）
- 品类规则改了，想重分类映射表里「其他」的行
- 首次全量映射 / 想先看规则覆盖率
- 用户提到「打品类」「分类新品」「更新品类映射」「其他」

❌ **不应该使用**:
- 改品类名/加新品类 → 先改 `mapper.py` 里的 `CATEGORY_LIST` 和 `RULES`，再跑
- 只想查某个商品属于哪个品类 → 直接查数据库 `商品品类映射表`

## 命令（从项目根目录 D:\代码\电商后台管理 运行）

| 场景 | 命令 |
|------|------|
| 增量更新（日常，最常用） | `python tools/category_mapper/mapper.py` |
| 重分类「其他」的行 | `python tools/category_mapper/mapper.py --reclassify` |
| 只看规则覆盖率（不写库不调 LLM） | `python tools/category_mapper/mapper.py --dry-run` |

## 核心机制

- **数据源**：`抖店单链接数据表`(商品编码) / `京东单链接数据表`(SPU) / `千牛单链接数据表`(商品ID)
- **去重键**：`(平台, 平台ID)` 联合键 —— 三平台 ID 各成体系，绝不能裸 ID 去重
- **分类顺序**：① 关键词规则（命中 1 个品类 → 直接定）→ ② DeepSeek 兜底（命中 0 或 ≥2 个品类，或规则未覆盖）
- **结果表**：`商品品类映射表`，主键 `(平台, 平台商品ID)`，字段含 `统一品类`、`商品名称快照`、`归类方式`(规则/LLM)、`归类时间`
- **一个商品只归一个品类**：映射表「统一品类」是单值，从根上杜绝一物多类

## 品类清单（24 类，单层平铺）

车品-车外养护：遮阳·防晒 / 车身防护 / 洗车清洁 / 养护·修复 / 车衣·车罩 / 玻璃贴膜 / 轮胎·应急

特殊+兜底：补差价链接 / 其他

## 改规则（改品类名 / 加关键词 / 加排除词）

规则都在 `tools/category_mapper/mapper.py` 顶部三个数据结构里：

- `CATEGORY_LIST` — 品类清单（顺序即 LLM 提示里的编号）
- `RULES` — 品类 → 强关键词列表（命中任一算该品类候选；命中 0 或 ≥2 个品类交给 LLM）
- `EXCLUDE` — 品类 → 排除词（标题命中排除词则跳过该品类，用于解决组合套装的主品类归属，如「脚垫+后备箱垫」→ 脚垫）

改完规则后：
1. 先 `--dry-run` 看覆盖率是否如预期
2. 再 `--reclassify` 重分类受影响的「其他」行

## 输出

结果和日志写在 `tools/category_mapper/output/`：规则分布、未决标题、映射抽样、LLM 解析失败日志等。
